# RssHub lite 维护范围

本版直接裁剪原版 AstrBot RSSHub 插件，保留基础订阅推送能力。此前面向处理器内部通信、扩展运行时和知识库的计划不再适用。

## 当前实现

| 模块 | 精简版行为 |
| --- | --- |
| RSS 抓取、去重与调度 | 保留原版基础链路和条件请求。 |
| 订阅与配置 | 保留增删查、启停、用户/会话默认值和普通发送选项。 |
| TOML 导入导出 | 保留基础字段；导入旧处理器字段时忽略并提示，导出不包含这些字段。 |
| 消息发送 | 保留平台适配、媒体解析/缓存、队列与失败重试。 |
| 推送历史和管理页 | 保留基础查询、管理和排障；移除处理器与知识库界面。 |
| AI 与知识库 | 移除注册、装配、执行和可配置入口。 |
| 旧数据库 | 保留兼容列，旧处理器内容不会执行。 |

## 回归检查

- 配置自愈删除废弃 AI/知识库字段；普通/手动显示配置及旧枚举按版本一次性迁移。
- 用户、订阅、会话入口拒绝处理器配置，旧 TOML 不能恢复处理器。
- 新订阅、轮询、测试推送及重试继续经过同一条基础发送链路。
- 推送历史保留正文、原始 XML、媒体和错误信息。
- 页面、命令和文档只展示本版可用能力。

详细维护约定见 [维护规则](./dev/maintenance.md)，验证命令见 [测试说明](./dev/testing.md)。

# 当前状态与维护方向

本版的范围是对原版做基础功能裁剪。订阅管理、轮询、消息推送、失败重试、历史记录和管理页继续沿用原版实现；内容处理器、LLM 工具和知识库能力已移除。

## 当前维护重点

1. 保持 RSS/Atom/JSON Feed、订阅启停及 TOML 导入导出的兼容性。
2. 保持 SQLite 旧数据可读，旧处理器字段不能重新启用任何 AI 执行路径。
3. 覆盖发送失败、重试、去重、平台媒体差异和插件卸载清理。
4. 同步命令、配置、Plugin Pages 与文档，避免留下不可用的入口。

## 后续工作边界

后续根据实际使用问题修复基础链路。原版处理器通信、Registry、外部运行时和 Routes 知识库扩展计划不属于本版维护范围。

实际功能以源码、测试和使用文档为准；本页不表示已经安排新的功能开发。维护检查见 [当前维护范围](../PLAN.md) 和 [测试说明](../dev/testing.md)。
